# Kam AI Discover packs

Kam AI is a private thinking and drafting tool that runs entirely on your Android phone. Its source code is no longer public.

**Get Kam AI:** on Google Play.

This repository keeps only what installed copies of Kam AI download: the Discover content packs, under **Releases**.

Kam AI is made by [B7 Collective](https://b7collective.com). Privacy policy: [kamsiob.com/kam-ai-privacy.html](https://kamsiob.com/kam-ai-privacy.html)
